The benchmark does not validate player controllers, vehicle handling, ragdolls or save migration. Full feature comparison and sources ↗

Both engines: single threaded, 60 Hz, identical seeded geometry, density 1 kg/m³, friction 0.5, restitution 0, no damping. Rapier uses 4 solver iterations; Box3D uses 4 substeps. Those settings are practical defaults, not equal solver work or equal accuracy. Actors use shared velocity steering, not either engine’s character controller. Local COOP/COEP headers enable finer timestamps; solver threads remain disabled.
